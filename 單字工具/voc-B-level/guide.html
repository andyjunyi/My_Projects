2. 三種查詢模式

點選搜尋框上方的分頁按鈕切換模式，再輸入關鍵字後按 搜尋 或 Enter。

🔤 單字查詢

在英文單字中搜尋「包含」指定字串，不區分大小寫。

  • 輸入 act → 找到 act、action、active、react、contact…
  • 輸入 friend → 找到 friend、friendly、friendship、boyfriend…
  • 輸入完整單字（如 apple）可精確查詢
🎵 音節查詢

有兩種用法：

  • 輸入數字：篩選特定音節數的單字
    例：3 → 找到所有三音節單字（ab-so-lute、beau-ti-ful…）
  • 輸入音標片段：在 KK 音標中搜尋含該音的單字
    例：eɪ → 找到含 [eɪ] 音的單字（make、say、name…）
    例：ɪŋ → 找到含 [-ɪŋ] 音的單字（sing、bring、king…）
💡 音節數分布：載入中…
🔡 字母查詢

有兩種用法：

  • 直接輸入字母組合：找以此開頭的單字
    例：pre → 找到 prepare、present、pretty、prevent…
  • 加 * 前綴：找「包含」此字母組合的單字（不限位置）
    例：*tion → 找到 action、question、station、education…
    例：*less → 找到 homeless、useless、careless…
🔠

3. 字母快捷列

搜尋框下方有 A–Z 的字母快捷按鈕，點一下即可切換至「字母查詢」模式，並立即列出以該字母開頭的所有單字。

  • 顏色較深的字母表示該字母開頭有單字可查詢
  • 顏色較淡（灰色）的字母表示詞庫中目前沒有以此字母開頭的單字
  • 點選後，搜尋框會自動填入該字母，結果立即更新
⚙️

7. 資料更新方法

本系統的資料來自 國中2000單高頻單字.xlsx，日後新增或修改內容只需以下步驟：

1
編輯 Excel 檔案 在「2000」工作表新增或修改單字列（英文、KK音標、中譯、例句、翻譯、詞性）。
若需補充考題頻率資料，請同步更新「考題高頻單字935_對應2000單排名」工作表。
2
重新產生資料檔 在同一目錄開啟命令提示字元（或終端機），執行：
python generate_data.py
腳本會自動讀取 Excel 並輸出新的 vocab_data.js。
3
重新整理瀏覽器 回到 index.html 的瀏覽器分頁，按 F5 或 Ctrl+R 重新整理，即可看到更新後的單字資料。
⚠️ 請確認 index.html、vocab_data.js、generate_data.py、國中2000單高頻單字.xlsx 均位於同一目錄下。
✅ 網頁使用 vocab_data.js 載入資料，可直接用瀏覽器雙擊 index.html 開啟，不需要架設 Web Server。

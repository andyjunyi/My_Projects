## 1. 系統架構

```
word_list.xlsx          ← 主資料庫（Excel）
    ↓ (sync_kk.py)
word_data.json          ← Fetch 備用載入
data.js                 ← 主要資料載入 (const WORD_DATA = [...])
index.html              ← 查詢網頁（單一 HTML）
```

**載入順序：**
1. 優先載入 `<script src="data.js">` — `const WORD_DATA` 全域變數
2. 如果 data.js 未定義（GitHub Pages 偶發），fallback 用 `fetch('word_data.json')`

## 3. 搜尋機制

### 觸發方式
- **按 Enter 鍵**觸發搜尋（`onkeydown` 事件）

### 比對邏輯
- **精確比對（大小寫不敏感）**：`(item.w || '').toLowerCase() !== q`
- 不支援模糊搜尋/部分比對

### 程式碼位置
```js
// 第 521 行
function doSearch() {
  const q = document.getElementById('searchInput').value.trim().toLowerCase();
  // ... 過濾邏輯
}
```

## 4. 最近查詢

### 儲存方式
- `localStorage`，key: `kk_recent`
- 最多 20 筆
- 每筆格式：`{ q: "abandon", time: 1747881600000 }`

### 記錄時機
- 按 Enter 搜尋後，**精確匹配**到資料庫中的單字才記錄
- 使用 `Array.find()` 比對 `d.w.toLowerCase() === q`
- 記錄的是資料庫中的原始大小寫（`match.w`），不是使用者輸入的大小寫

### 程式碼位置
```js
// 第 546-549 行
if (q) {
  const match = allData.find(d => d.w && d.w.toLowerCase() === q);
  if (match) recordSearch(match.w);
}
```

### 顯示
- 卡片式標籤，顯示單字、搜尋筆數、時間（幾分鐘前）
- 點擊可重複搜尋
- 可清空全部

## 5. 輸入框清空機制

### 問題
直接設定 `inp.value = ''` 會觸發 `oninput` 事件，導致 `doSearch()` 再次執行（q 為空，顯示全部單字）。

### 解決方案
使用 `setTimeout(() => { inp.value = ''; }, 0)` 將清空操作延後到事件循環的下一個 tick，避免與 `oninput` 事件鏈互相干擾。

### 程式碼位置
```js
// 第 550-554 行
setTimeout(() => {
  const inp = document.getElementById('searchInput');
  inp.value = '';
  inp.focus();
}, 0);
```

### 歷次嘗試（失敗方案記錄）
1. ❌ 直接賦值 `inp.value = ''` — 觸發 `oninput` 迴圈
2. ❌ `setTimeout(10)` — 手機 Safari/Chrome 仍然觸發
3. ❌ `skipNextInput` flag — 清空後的 `oninput` 會 reset flag，但手機上觸發多次導致 flag 狀態錯亂
4. ✅ `setTimeout(0)` — 正確解法，事件鏈完成後才清空

## 6. 中譯詞場合併

### 問題
原始資料中，同一個詞類出現多次（如 `(形) 強制的；必須的　(形) 法定的；規定的`），導致卡片顯示冗長。

### 解決方案
合併同詞類的中譯，最多保留 3 個：

```
(形) 強制的；必須的　(形) 法定的；規定的
→ (形) 強制的；必須的；法定的
```

### 合併腳本 `/tmp/merge_zh.py`

```python
# 解析正則
pattern = r'(?:（([^）]*)）|\(([^)]*)\))\s*([^（(]*)'

# 1. 用 re.finditer 提取所有 (詞類) 中譯
# 2. 用 OrderedDict 合併同詞類
# 3. 每個詞類最多取前 3 個中譯，用 ；連接
# 4. 不同詞類用全形空格（　）分隔
```

### 執行結果
- 總筆數：15,206
- 有修改：4,213 筆
- 備份：`word_list_bak.xlsx`

### 邊緣案例
- `aboard: (副) 在船（車、飛機）上` — 括號內含逗號被誤判，人工檢查
- `aunt: (名) 阿姨；姑媽；螞蟻` — `螞蟻` 是 `ant` 的誤植（資料問題）
- 不同詞類（如 `(形)...　(名)...`）保持不變

## 7. GitHub Pages 部署

### 遠端
```bash
git remote -v
# origin  git@github.com:andyjunyi/My_Projects.git (fetch)
# origin  git@github.com:andyjunyi/My_Projects.git (push)
```

### 路徑對應
- GitHub 根目錄：`https://andyjunyi.github.io/My_Projects/`
- 實際頁面：`https://andyjunyi.github.io/My_Projects/單字工具/高中單字KK音標/index.html`

### 注意事項
- GitHub Pages 對 `.json` 檔案的 MIME type 偶發 `application/octet-stream`，導致 `fetch()` 失敗
- **解法：** 主要資料載入使用 `<script src="data.js">`（JS 變數宣告），並加上版本參數快取破壞：`data.js?v=2`

## 8. 資料同步流程

### 修改單字
1. 在網頁上點擊欄位直接編輯
2. 修改會記錄在 `changes` 物件中
3. 點「🔄 同步」按鈕查看修改內容

### 同步到 Excel
```bash
# 複製修改內容到 changes.tsv
python3 sync_kk.py < changes.tsv
# 會重新產生 word_data.json 和 data.js
```

### 同步腳本 `sync_kk.py`
- 讀取 `changes.tsv`（格式：`單字\t欄位\t原值\t新值`）
- 更新 `word_list.xlsx`
- 重新輸出 `word_data.json` 和 `data.js`

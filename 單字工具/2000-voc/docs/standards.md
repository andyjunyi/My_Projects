## 詞性標示（中文）

(名)・(動)・(形)・(副)・(介)・(連)・(代)・(助)

## 例句撰寫原則

- 句子長度：10–20 個單字為佳
- 情境優先：學校生活、日常對話、時事（適齡）
- 避免：過於複雜的文化背景、抽象概念、負面情緒
- 每個知識點例句不重複使用同一情境
- 超綱詞彙需加括號標示中文

## 語言風格

- 例句語言：英文
- 說明語言：繁體中文
- 術語：中英對照（如：現在完成式 Present Perfect Tense）
- 語氣：親切、鼓勵，適合青少年

## 五大知識類別格式規範

### 單字
- KK 音標 + 詞性（中文）+ 中文釋義
- 多詞性須分開列出
- 標示版本（共同 / 翰林 / 康軒 / 南一）

### 文法
- 架構：規則 → 例外 → 例句 → 常見錯誤
- 提供 ✗/✓ 對照表
- 標示各版本對應章節

### 搭配詞
- 格式：動詞 + 名詞 / 形容詞 + 名詞 / 名詞 + 動詞
- 每組 2 個例句 + 語感提示

### 片語
- 提供字面意思與實際意思對照
- 標示使用情境（正式 / 非正式 / 口語）

### 句型
- 格式：結構 → 中文說明 → 例句 × 3
- 提供替換練習模板

## 注意事項

- 所有例句需符合國中課綱範圍，避免超綱詞彙（除非特別標示）
- 文法說明須與台灣三大版本共同認可的教學邏輯一致
- 若遇台灣與英美用法差異，需特別說明
- 影片腳本口語化，避免唸起來像「在讀課文」

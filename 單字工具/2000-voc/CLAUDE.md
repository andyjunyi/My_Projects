# CLAUDE.md — 中學英文教學內容整合專案

## 專案概述

台灣國中英文教學內容整合專案，目標是系統性整合中學生必學的英文知識（單字、文法、搭配詞、片語、句型），產出教學網頁並製作線上教學影片。

**目標學習者：** 台灣國中生（7–9年級）／CEFR A1–B1／國中會考備考

## 核心規範（常駐）

### 詞性標示（中文）
(名)・(動)・(形)・(副)・(介)・(連)・(代)・(助)

### 難度標記
- 🟢 基礎（A1–A2）：7年級／基礎 1,200 字
- 🟡 中級（B1）：8–9年級／進階 800 字
- 🔴 進階（B1+）：會考衝刺／資優生

### 單字版本標注
共同 / 翰林 / 康軒 / 南一（三版均有則標「共同」）

### 例句原則
- 長度 10–20 字、貼近學生生活、無超綱詞彙
- 說明用繁體中文，術語中英對照

## 常用工作流程

**批次處理單字：**
→ 先讀 `docs/roles/vocabulary.md`，再讀 `data/vocabulary/wordlist.md`

**出題：**
→ 先讀 `docs/roles/quiz.md`

**影片腳本：**
→ 先讀 `docs/roles/script.md`

**網頁元件：**
→ 先讀 `docs/roles/webdev.md`

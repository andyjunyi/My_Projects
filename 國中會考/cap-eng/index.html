📊 13年命題規律洞察

完成式稱霸榜首現在完成式12年連考，過去完成式10年出現，兩者合計是最穩定的考點。
複雜句結構為核心關係子句、間接問句、條件句構成「句型整合能力」三大支柱，每年必見其中2項以上。
情境整合考驗文法不單獨出現，均融入閱讀段落，強調在真實語境中識別文法的能力。
連續年份出現規律110–114年是近五年高頻期，本表標記為「熱門年份」(紫色)，命中率最高。
Tier 1–2 必全掌握前12個考點在近5年（110–114）幾乎全數出現，備考優先投入這12項。
詞性靈活運用分詞、使役、強調等進階句型（Tier 3）雖頻率較低，但每年仍有1–2題出現。

📋115年文法備考學習計畫（4週攻略）
第一週 ─ 完成式核心
時態精準掌控
  • 現在完成式：結構、用法、since/for 搭配
  • 過去完成式：before/after/by the time 結合
  • 現在完成進行式：has/have been + Ving
  • 時態比較：簡單過去 vs 現在完成式
  • 每日練習：改寫完成式句子 × 10題
第二週 ─ 複雜句結構
句型整合能力
  • 關係子句：who / which / that / where / when
  • 間接問句：whether / if / 疑問詞 + 直述語序
  • 條件句：第一、二、三條件句完整練習
  • 假設語氣：I wish... / If I were...
  • 每日練習：合併句子練習 × 8組
第三週 ─ 動詞進階
動詞句型強化
  • 情態助動詞語意辨別（can vs may vs must）
  • used to + V vs be used to + Ving
  • 被動語態：各時態被動形式轉換
  • 動名詞 vs 不定詞：常見動詞搭配記憶
  • 使役動詞：make/let/have/get + 受詞 + V原
第四週 ─ 綜合衝刺
模擬測驗＋弱點強化
  • 比較級最高級：規則 / 不規則 / 雙重比較
  • 附加問句：助動詞對應 + 正反搭配規則
  • 分詞片語：現在分詞 / 過去分詞當修飾語
  • 強調句型：It is...that / What...is 練習
  • 每日：歷屆試題文法題全題型計時練習

背面：中文 + 例句。隨身攜帶，零碎時間複習。
📖 上下文推敲法 遇到不認識的字，先看前後句意再猜。會考設計讓你可以推測，不需要認識每個字。
🗂️ 主題分組記憶 把相關詞彙一起記（如：hospital, doctor, health, hurt），情境連結讓記憶更牢固。
⏱️ 計時練習習慣 正式考試60分鐘43題，平均每題不到1.5分鐘。每次模擬都要嚴格計時，養成節奏感。
📝 詞性變化一起學 一個字學四種：health → healthy → healthily → healthier。文法選擇題常考詞性。
🔄 間隔複習原則 新字學完後，第1天、第3天、第7天、第14天各複習一次，符合記憶曲線，效果最佳。

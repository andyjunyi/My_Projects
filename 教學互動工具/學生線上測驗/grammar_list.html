動詞形式與用法 (Verb Forms)

1. 不定詞 (to Vr.) 與 動名詞 (V-ing)

to Vr.： 表示目的、尚未發生。常用詞：want, hope, plan。

V-ing： 表示事實、經驗、進行。常用詞：enjoy, finish, keep。

forget/remember + to Vr. (要去辦)
forget/remember + V-ing (曾做過)

2. V-ing 當主詞

當動名詞作為主詞時，動詞須用單數。

Playing basketball is fun.

3. 感官動詞 (Sensory Verbs)

主動: 強調事實 V
主動: 強調正在進行 V-ing
被動: 受詞被處理 PP

Ex: I heard my name called.

4. 使役動詞 (Causative Verbs)

  • make / have / let + O + Vr.
  • get + O + to Vr.

5. 授與動詞與介係詞

to: give, send, show, tell
for: buy, make, cook, get

6. used to 的三種型態

1. used to + Vr. (過去習慣)

2. be used to + Ving (現在習慣於)

3. be used to + Vr. (被用來做...)

2

時態與一致性 (Tenses)

7-8. 主詞動詞一致與三單

三單主詞 (He/She/It) 動詞需加 -s/es。

注意: A + with/as well as + B
👉 動詞需看 A。

9-10. 完成式與時態一致

完成式: 強調持續或經驗 (since/for)。

過去式: 特定時間點 ($V\text{-ed}$)。

# KK Lookup 專案規則

## 檔案結構

`國中935單.xlsx` 含兩個分頁：

| 分頁 | 中譯欄位 | 說明 |
|------|----------|------|
| 935  | D 欄、N 欄（內容相同，需同步更新） | 國中 935 單字 |
| 2000 | C 欄 | 2000 單字總表 |

2000 分頁欄位順序：A 英文、B KK音標、C 中譯、D 例句、E 翻譯（例句中譯）、F 詞性

---

## 詞類標記規則

一律使用中文詞類標記，不使用英文縮寫：

| 英文 | 中文 |
|------|------|
| n.   | (名) |
| v.   | (動) |
| adj. | (形) |
| adv. | (副) |
| prep.| (介) |
| conj.| (連) |
| aux. | (助) |
| det. | (限) |
| interj. | (感) |
| pron.| (代) |
| num. | (數) |

---

## 中譯填寫規則

1. **同詞類多義**：列最常用的兩個，以「；」分隔，例如：`(名) 時間；次數`
2. **補充第二義**：若目前只有一個意思，但有其他國中/高中常用意思，補上第二個
3. **多詞類**：最多列兩個詞類，每個詞類最多兩個中譯，詞類之間以空格分隔，例如：`(動) 工作；運作 (名) 工作`
4. **保留原有括號說明**：如 `(使)` 等原有說明保留，例如：`(動) (使)保持；繼續`
5. 翻譯用字以國中至高中程度為準，精簡為原則

---

## 新增單字規則

新增單字至 2000 分頁時，須填入以下欄位：

- **A 英文**：單字原形
- **B KK音標**：KK 音標（從圖片或來源資料取得）
- **C 中譯**：依上述中譯規則填寫
- **D 例句**：英文例句（參見下方例句規則）
- **E 翻譯**：例句的中文翻譯

---

## 例句規則

- 句型簡單清楚，適合國中至高中程度
- 一個單字一句，示範該單字的主要用法
- 用字風格參考 2000 分頁既有例句（主詞 + 動詞 + 受詞/補語，約 8–15 個英文字）
- 中文翻譯為例句的直接對應翻譯

---

## KK 音標書寫規則

- **`eɪ` 統一簡化為 `e`**：例如 `pleɪn` → `plen`、`peɪd` → `ped`、`pəˈreɪd` → `pəˈred`

---

## 操作備註

- 修改前先備份：`shutil.copy('國中935單.xlsx', '國中935單.xlsx.bak')`
- 935 分頁的 D 欄與 N 欄內容相同，須同步更新
- 新增單字用 `ws.append()` 附加至末尾；若單字已存在則直接更新中譯欄

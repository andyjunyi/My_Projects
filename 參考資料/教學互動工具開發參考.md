# 教學互動工具 — 開發參考

適用專案：jutor-qr / jutor_intro / dwhs-english / 學生線上測驗 / collocation-backup / sentence-pattern-site

## 目標受眾
- 台灣國中英文老師（管理端）
- 台灣國中生（學生端）
- 部分延伸至高中生（sentence-pattern-site）

## 常見互動模式

### 1. QR Code 出題（jutor-qr）
- 老師端：generator.html（產生 QR 碼）
- 學生端：student.html（掃碼後自動帶入班級/座號/姓名）
- 批次產生：batch-generator.html（A4 講義，1 人 1 張 / 2 人 1 張）
- 成績串接：Google Apps Script POST → Google Sheets

**URL Query String 格式**：
```
student.html?class=301&num=12&name=王小明
```

**GAS POST 格式**：
```json
{
  "class": "301",
  "num": "12",
  "name": "王小明",
  "score": 85,
  "time": "2026-05-22T09:00:00",
  "task": "朗讀練習"
}
```

### 2. 搭配詞比對（collocation-backup / sr-collocation）
- 輸入文字 → 自動比對未收錄的搭配詞
- 左右雙欄佈局（輸入區 + 結果區）
- 搭配詞分類：動詞+名詞、形容詞+名詞、片語動詞等

**搭配詞資料格式**：
```json
{
  "phrase": "take care of",
  "type": "動詞 + 名詞",
  "chinese": "照顧",
  "keywords": ["take", "care"],
  "example": {
    "english": "She takes care of her younger brother.",
    "chinese": "她照顧她的弟弟。",
    "grammar_point": "take care of + 人"
  },
  "vocabulary": [
    {"word": "take", "pos": "v.", "chinese": "拿；帶"}
  ],
  "sentence_pattern": {
    "pattern": "S + take care of + O",
    "example": "I take care of my pet."
  }
}
```

### 3. 線上測驗（學生線上測驗）
- 主題式測驗：金錢篇、時間篇、人物篇
- 測驗流程：選主題 → 單字複習列表 → 測驗 → 回饋分析
- 單字卡格式：英文 / KK 音標 / 中文

**單字卡 HTML 結構**：
```html
<div class="word-card">
  <span class="word-en">person</span>
  <span class="word-kk">/ˈpɝsn/</span>
  <span class="word-zh">人</span>
</div>
```

**測驗選項**：2×2 grid 四選一

### 4. 句型學習（sentence-pattern-site）
- Next.js 16 + React 19 + TypeScript + Tailwind CSS 4
- 8 大句型章節（虛主詞、條件句、比較、關係子句等）
- AI 批改（Claude API）+ AI 提示
- Supabase 資料庫
- 深色模式支援

**JSON 資料格式**：
```json
{
  "code": "1-1",
  "chapter": 1,
  "title": "It 虛主詞句型",
  "formula": "It is + adj + to + V",
  "explanation": "當主詞是 to V 時，常用 It 代替...",
  "examples": [
    {
      "eng": "It is important to study hard.",
      "chi": "努力學習很重要。"
    }
  ],
  "exercises": [
    {
      "type": "translation",
      "stem": "___ ___ important ___ ___ hard.",
      "answer": "It is to study"
    }
  ]
}
```

## 老師工具設計原則

1. **批次產出**：QR 批次產生器支援 A4 列印（1 人 1 張 / 2 人 1 張）
2. **零安裝**：老師在本機開啟 HTML 即可使用
3. **列印友善**：含學校抬頭、使用步驟、老師的話
4. **學生自動化**：QR 掃碼自動帶入身份資訊
5. **數據追蹤**：成績自動寫入 Google Sheets

## 學生平台設計原則

1. **低門檻**：手機可開啟，無需註冊
2. **即時回饋**：作答後立即顯示對錯與詳解
3. **多模態**：視覺（卡片）+ 互動（點選）+ 聽覺（Jutor AI）
4. **遊戲化**：排行榜、進度條、等級徽章
5. **鼓勵語氣**：「只要熟讀這 935 個單字，就能掌握會考英文！」

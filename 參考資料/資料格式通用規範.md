# 資料格式與欄位命名 — 通用規範

## 所有專案共通原則

1. **繁體中文（zh-TW）** — 教學說明、註釋、介面全部用繁體
2. **KK 音標** — 國中層級專案必備，高中層級可省略
3. **雙語例句** — 每句英文例句都附中文翻譯
4. **頻率統計** — 出現次數、年數、百分比

---

## 欄位命名對照表

### 單字核心欄位

| 建議名稱 | 曾用名 | 說明 | 必填 |
|----------|--------|------|------|
| `word` | `w`, `vocab` | 英文單字 | ✅ |
| `kk` | `phonetic`, `phoneme`, `ph`, `kk_phonetics` | KK 音標 | 國中✅ 高中❌ |
| `zh` | `chinese`, `chinese_meaning`, `definition_zh`, `hint_zh` | 中文+詞類 | ✅ |
| `pos` | — | 詞性縮寫（高中用） | 高中✅ |
| `example` | `ex`, `eng`, `english` | 英文例句 | ✅ |
| `example_zh` | `exz`, `chi` | 例句中譯 | ✅ |

### 統計欄位

| 建議名稱 | 曾用名 | 說明 |
|----------|--------|------|
| `frequency` | `f`, `total`, `rank` | 出現次數 |
| `years` | `y`, `years_count` | 出現年數 |
| `years_list` | — | 年分陣列 `[110,111,112]` |
| `percent` | `freq_percent` | 頻率百分比 |
| `cumulative` | `cumulative_percent` | 累計百分比 |

### 分級欄位

| 建議名稱 | 曾用名 | 說明 | 值 |
|----------|--------|------|----|
| `level` | `lv` | 課綱級別 | `1200`, `800`, `15000` |
| `cefr` | — | CEFR 等級 | `A1`, `A2`, `B1`, `B2` |
| `core300` | `c` | 核心300 | `true`, `false` |
| `consolidate450` | `g` | 鞏固450 | `true`, `false` |
| `topic` | — | 主題分類 | `人物`, `金錢`, `教育` |
| `syllable_count` | — | 音節數 | 整數 |

## KK 音標統一規範

### 國中層級（必備）
```json
{ "kk": "/ˈpɝsn/" }        // 斜線包圍（顯示用）
{ "kk": "ˈpɝsn" }          // 無斜線（資料儲存用）
```

### 高中層級（可省略）
```json
{ "pos": "n." }             // 用詞性替代
```

### 簡化規則
| 原 KK | 簡化後 | 範例 |
|-------|--------|------|
| eɪ | e | pleɪ → ple |
| oʊ | o | ɡoʊ → ɡo |
| aɪ | — | 保留 |
| aʊ | — | 保留 |

## 中文註釋格式規則

### 單一詞類
```
(名) 學生
(動) 學習
```

### 同一詞類兩個中譯（用頓號）
```
(動) 得到、獲得
(名) 時間、次數
```

### 多詞類（空格分隔，最多 2 詞類各 2 義）
```
(動) 工作；運作 (名) 工作
(動) 離開；放下 (名) 假期
```

## 資料儲存選擇

| 資料量 | 格式 | 適合場景 |
|--------|------|----------|
| < 100 筆 | HTML 內嵌 `<script>` | 小型測驗、簡單查詢 |
| 100–10,000 筆 | 外部 JS 檔案（data.js） | 單字庫、搭配詞庫 |
| 10,000+ 筆 | JSON（fetch 載入）| Voc_15000 等級 |
| 結構化表格 | Excel (.xlsx) | 主資料庫、人工編輯 |
| 中繼格式 | CSV | Python 處理用 |

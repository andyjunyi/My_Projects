# 單字查詢系統 — 開發參考

適用專案：jr-voc / voc-935 / voc-B-level / voc_online / KK_Lookup / voc-king

## 目標受眾
- 台灣國中生（會考備考）
- 部分延伸至高中生（voc-king、Voc_15000）

## 核心功能模組

### 1. 單字查詢
- 搜尋列（文字即時過濾或送出查詢）
- 結果列表（表格 / 卡片）
- 篩選器：級別（1200/800）、CEFR、主題、核心/鞏固/其他
- 排序：A→Z、頻率高→低、難度低→高

**高級查詢模式（voc-B-level）**：
- 單字查詢 / 音節查詢 / 字母查詢 三種模式
- 字母快捷列（A–Z）

### 2. 統計呈現
- 出現次數、年數、年分分布（彩色年度標籤）
- 頻率進度條（視覺化）
- 累計百分比
- 年分分布格式：`{110: 3, 111: 5, 112: 2, 113: 1, 114: 0}`

### 3. 學習模式
- 單字列表（基本閱讀）
- 閃卡（翻轉動畫）
- 中翻英
- 選擇題（四選一）
- 句子翻譯
- Day-based 學習計畫（如 32 天 935 字）

### 4. 即時搶答（voc-king 獨有）
- 老師開房、學生手機加入
- Socket.IO 即時通訊
- 四選一選擇題，限時作答
- 排行榜（金/銀/銅）

## 資料欄位規範

### 精簡版（voc-935 格式）
```json
{
  "w": "person",          // word
  "ph": "ˈpɝsn",         // KK音標
  "zh": "(n.) 人",        // 中文+詞類
  "ex": "He is a nice person.",  // 例句
  "exz": "他是個好人。",         // 例句中譯
  "f": 132,               // 出現頻率
  "y": 13,                // 出現年數
  "lv": "1200",           // 課綱級別
  "c": true,              // 核心300
  "g": false              // 鞏固450
}
```

### 完整版（voc-B-level 格式）
```json
{
  "word": "person",
  "phonetic": "ˈpɝsn",      // KK音標（無斜線）
  "chinese": "(n.) 人",     // 中文+詞類
  "example": "She is a kind person.",
  "example_zh": "她是個善良的人。",
  "pos": "n.",              // 詞性縮寫
  "rank_935": 1,            // 935單排序
  "frequency": 132,         // 總次數
  "years_count": 13,        // 出現年數
  "years_list": [110,111,112,113,114],
  "freq_percent": 3.42,     // 百分比
  "cumulative_percent": 3.42,
  "cefr": "A2",             // CEFR分級
  "level": "1200",          // 課綱級別
  "topic": "人物",          // 主題分類
  "core300": true,          // 核心300
  "consolidate450": false,  // 鞏固450
  "syllable_count": 2       // 音節數
}
```

## KK 音標處理規則

### 音標格式
- 無方括號／斜線包圍：`ˈæpl`
- 斜線包圍：`/ˈæpl/`（用於 HTML 顯示）
- 一律使用 KK 音標，非 IPA

### 簡化規則（KK_Lookup 定義）
- `eɪ` → `e`（如 `pleɪ` → `ple`）
- `oʊ` → `o`（如 `ɡoʊ` → `ɡo`）
- 保留重音符號 `ˈ` 和 `ˌ`

### 顯示樣式
- monospace 字型（`DM Mono` 或 `'Courier New'`）
- 灰色文字 `#64748b`
- 行內顯示於單字右方或下方

## 分頁規則
- 每頁 50 筆
- 上下頁按鈕 + 頁碼指示
- Sticky 頂部分頁器（可與篩選列合併）

## 學習計畫格式

### 32 天計畫（voc-935）
```
核心300：Day 1–10（每天 30 字）
鞏固450：Day 11–25（每天 30 字）
其他：Day 26–32（每天 30 字）
```

### 30 天衝刺（cap-eng）
```
Week 1（Day 1–7）：基礎單字
Week 2（Day 8–14）：進階單字
Week 3（Day 15–21）：難題加強
Week 4（Day 22–30）：衝刺模擬
```

- **voc-B-level**：最完整的資料欄位+三重查詢模式
- **voc-king**：唯一含即時互動的遊戲化設計
- **KK_Lookup**：KK 音標處理規則最詳盡

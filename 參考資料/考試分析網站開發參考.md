# 考試分析網站 — 開發參考

適用專案：cap-eng / cap-listening / gsat-english-hub / toeic

## 各考試層級差異

| 項目 | 國中會考（cap-eng） | 大學學測（gsat-english-hub） | 多益（toeic） |
|------|---------------------|-----------------------------|---------------|
| 受眾 | 國三考生 | 高中生 | 一般大眾 |
| 技術 | 純靜態 HTML/Python | React 19 + Vite + Tailwind | 純靜態 HTML + GAS |
| KK音標 | ✅ 全部標註 | ❌ 無（pos 欄位替代） | ❌ 無 |
| 詞類標示 | 隱含於中文 | `pos` 英文縮寫 | 英文解析中說明 |
| 年份 | 民國 102–114 | 學年度 93–115 | 無 |
| 資料來源 | PDF 人工統計 | 手動整理 | 手動出題 |
| 部署 | 本機檔案 | Vercel + GitHub Actions | 本機 + Google Sheets |

## 共通功能

### 1. 考試分析
- 歷屆試題詞頻統計
- 文法考點分布（按 Tier 分級）
- 年度比較趨勢

### 2. 題庫系統
- 閱讀題／聽力題／文法題
- 選項 4 選 1
- 自動評分
- 詳解（英文解析 + 中文翻譯）

### 3. 學習路徑
- Tier 分層教學法（T1→T5 + Review）
- 30 天讀書計畫
- 各 tier 完成後需通過複習關卡才能解鎖下一層

### 4. 成績記錄
- 測驗結果儲存（Google Sheets + Apps Script）
- 分項得分統計
- 答題狀態視覺化

## 文法分級系統（cap-eng 格式）

### Tier 1（必考基礎）
- 名詞單複數、冠詞、be 動詞、一般動詞現在式
- 顏色：深藍 `#1d4ed8`

### Tier 2（重要文法）
- 進行式、未來式、比較級、介系詞
- 顏色：翠綠 `#0d7a5f` 或 青色 `#22b4a0`

### Tier 3（進階文法）
- 被動語態、現在完成式、關係代名詞、假設語氣
- 顏色：琥珀 `#f59e0b`

## 學測分層系統（gsat-english-hub 格式）

| Tier | 說明 | 顏色代碼 | 描述 |
|------|------|----------|------|
| T1 | Level 1 基礎 | `#996500` 深金 | 詞性、時態基本概念 |
| T2 | Level 2 鞏固 | `#0d7a5f` 翠綠 | 動詞進階、不定詞 |
| T3 | Level 3 進階 | `#1a5fb4` 藍 | 關係子句、比較 |
| T4 | Level 4 挑戰 | `#6b2fa0` 紫 | 分詞構句、倒裝句 |
| T5 | Level 5 精通 | `#b52634` 紅 | 假設語氣、強調句 |
| R1–R5 | 複習關卡 | `#1265a8` 藍 | 各 tier 完成後解鎖 |

## 學習計畫文件結構（cap-eng）

## 特殊設計提醒

### cap-eng
- 民國年份（102–114），非西元
- KK 音標格式 `/ˈpipəl/`（斜線包圍）
- 單字中譯如「商店；購物」（分號隔開多義）
- 無明確 POS tag（詞類資訊隱含於中譯）

### gsat-english-hub
- 無 KK 音標（學測層級）
- `pos` 欄位：`adj.` / `n.` / `v.`
- emoji 裝飾功能圖示（📚🗺️✏️🎬🛠️）
- Vercel deploy + GitHub Actions CI/CD
- CSS 變數命名：`--primary: #4f6ef7`

### toeic
- 倒數計時器（sticky topbar）
- 側邊題號導航（5×5 grid dots）
- 答題狀態顏色：藍=已答、綠=正確、紅=錯誤
- Part 7 雙欄/三欄文章排版

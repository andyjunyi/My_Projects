## 一、KK 音標工具（KK_Lookup / phonics-site）

### 專案定位
- **KK_Lookup**：查詢工具（Flask 後端 + DeepSeek AI 補字）
- **phonics-site**：教學網站（自然發音規則 + 聽音拼字遊戲）

### KK 音標資料欄位（phonics 資料庫）
```json
{
  "lesson": 1,
  "part": 1,
  "part_name": "短母音",
  "title": "短母音 a",
  "phonics_type": "short_vowel",
  "level": "basic",
  "words": [
    {
      "word": "cat",
      "phoneme": "kæt",
      "pos": "n.",
      "hint_zh": "貓",
      "syllable_split": "cat"
    }
  ]
}
```

### 通用 KK 音標格式
- **欄位名**：`phonetic`、`phoneme`、`kk_phonetics`、`ph`（四種皆出現過）
- **建議統一為**：`kk` 或 `phonetic`
- 格式：`ˈpɝsn`（無包圍）或 `/ˈpɝsn/`（斜線包圍，用於顯示）

### 自然發音分類
| 類型 | 包含 |
|------|------|
| 短母音 | a, e, i, o, u |
| 長母音 | a, e, i, o, u (silent e) |
| R 控制母音 | ar, er, ir, or, ur |
| 雙字母組合 | sh, ch, th, wh, ph |
| 混合音 | bl, cl, fl, gr, st, nd |
| 不發音字母 | kn, wr, mb, gh |
| 特殊規則 | oo, ou, ow, oi, au |

## 二、文法專案（grammar / sentence-pattern-site）

### grammar 資料夾
- 目前僅含 `node_modules/@anthropic-ai/sdk`
- 推測為實驗中專案，尚無前端成品

### sentence-pattern-site（Next.js 句型平台）

**8 大句型章節**：
1. It 虛主詞 / There be
2. 條件句（if）
3. 比較級與最高級
4. 關係子句（who/which/that）
5. 動詞進階（使役動詞、感官動詞）
6. 不定詞與動名詞
7. 分詞構句
8. 連接詞（although, because, so...that）

**路由結構**：
```
/                             → 句型清單（搜尋 + 分類篩選）
/patterns/[code]              → 單一句型詳解（公式→例句→練習→AI批改）
/api/ai-grade                 → AI 批改翻譯練習 (POST)
/api/ai-hint                  → AI 給提示 (POST)
```

**API 格式**：
```typescript
// POST /api/ai-grade
{ patternCode: "1-1", userAnswer: "It is important to study." }
// Response
{ score: 85, feedback: "句子結構正確，注意形容詞位置...", suggestion: "可以改成..." }
```

## 三、翻譯與句子分析

### chinese-to-english（中翻英引導練習）
- React 19 + Vite 8 + Claude API
- 5 步驟引導法：
  1. 找主角（主詞）
  2. 找動作（動詞）
  3. 找修飾（形容詞/副詞/介詞片語）
  4. 組合句子
  5. 完整翻譯

**API 回傳格式**：
```json
{
  "sentence": "他在圖書館認真讀書。",
  "steps": [
    {
      "step": 1,
      "title": "找出主角",
      "chinese": {
        "question": "這句話的主角是誰？",
        "hint": "誰在讀書？",
        "answer": "他",
        "explanation": "主詞是「他」，英文用 He"
      },
      "english": {
        "question": "Who is the subject?",
        "hint": "Who is studying?",
        "answer": "He",
        "explanation": "\"He\" is the subject pronoun."
      }
    }
  ]
}
```

### sentence-analyzer（長句解析器）
- 純 HTML/CSS/JS + Supabase + Claude API
- SVOC 分析方式，詞類著色系統：
  - 主詞：**藍色**
  - 動詞：**紅色**
  - 受詞：**橘色**
  - 補語：**綠色**
  - 修飾語：**紫色**
  - 連接詞：**灰色**
- 字體：Playfair Display（裝飾）+ Noto Serif TC（襯線中文）

### translation（翻譯工具三合一）
- index.html：暗色主題，計時測驗（暗色 `#0d0f14` + 藍色 `#4a8cff`）
- translator.html：步驟式引導翻譯教室（Tailwind 淺色）
- generator.html：暗色主題，題目產生器（暗色 `#0a0c10` + 藍色 `#3b82f6`）

## 四、影音頻道工具（Andy-Youtube）

### 專案架構
- 三欄式佈局：
  - 左：側邊欄（年度切換 + 分類 + 單字清單）
  - 中：YouTube iframe 播放器
  - 右：PDF 講義 iframe

### 年度範圍
- 93–115 學年度（民國年）
- 影片來源：@dwhsvideo（大灣高中影音教學頻道，22.5K 訂閱）

### PDF 命名規則
```
{年度}-文意字彙-all-學生講義-均一.pdf
093-文意字彙-all-學生講義-均一.pdf
...
115-all-學生自學講義.pdf
```

### 詞彙卡片格式
```json
{
  "word-en": "abandon",
  "word-pos": "v.",
  "word-ph": "/əˈbændən/",
  "word-zh": "放棄",
  "word-example": "They abandoned the plan."
}
```

### YouTube 整合技巧
- 使用 YouTube iframe API 或直接嵌入 `<iframe>`
- 年度切換時更新 iframe src
- 影片清單資料以 JSON 管理
- 詞彙 + 影片 + PDF 三維對應（同年度同一題號）

## 跨專案共通模式

### 1. AI 串接方式
| 專案 | AI 服務 | 用途 |
|------|---------|------|
| KK_Lookup | DeepSeek API | 補字查詢 |
| sentence-pattern-site | Claude API | 批改翻譯 + 提示 |
| chinese-to-english | Claude Sonnet 4 | 5 步驟引導 |
| sentence-analyzer | Claude API | 句子結構解析 |

### 2. 資料來源途徑
- **Excel (.xlsx)**：單字資料庫主要格式（openpyxl 讀取）
- **JSON**：前端載入的資料格式
- **CSV**：中繼試算表格式
- **內嵌 JS array**：小型專案直接寫在 HTML/JS 中

### 3. 翻譯類專案設計哲學
- 不是給答案，而是**引導思考**
- 步驟式教學（拆解→組合→驗證）
- AI 當作助教（給提示，非直接翻譯）
- 搭配詞庫輔助（串接 collocationData）

### 4. 年度與日期格式
- **民國年**：93、102、110、114 等
- **學年度**：93–115 學年度
- **中西並存**：除非特別註明，預設使用民國年
